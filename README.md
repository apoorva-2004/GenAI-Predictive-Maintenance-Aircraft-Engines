# 🛠️ GenAI-Powered Predictive Maintenance System for Aircraft Engines

## 📌 Project Overview

Aircraft engines generate large volumes of sensor data during operation. Predicting potential failures in advance is critical to ensure safety, reduce maintenance costs, and prevent unplanned downtime.

This project presents an **end-to-end predictive maintenance system** that combines **Machine Learning** and **Generative AI (GenAI)** to predict engine failure risk and generate **human-readable maintenance explanations**.

A Random Forest model is used to predict failure based on Remaining Useful Life (RUL), while a GenAI model converts predictions and key sensor signals into **clear maintenance insights** that can be easily understood by engineers and decision-makers.

---

## 🎯 Problem Statement

Traditional predictive maintenance systems often provide **only numeric predictions**, which can be difficult for maintenance teams to interpret.

This project addresses that gap by:

* Predicting **engine failure risk**
* Estimating **Remaining Useful Life (RUL)**
* Explaining predictions using **natural language generated by GenAI**

The solution follows a structured data science and AI pipeline:

## 🗂️ Dataset Description

The project uses an **Aircraft Engine Predictive Maintenance dataset**, containing multivariate time-series sensor data.

### Dataset Features:

* **Engine identifiers** (`unit_number`)
* **Operational cycles** (`time_cycles`)
* **Operational settings** (`setting_1`, `setting_2`, `setting_3`)
* **Sensor measurements** (`s_1` to `s_21`)
* **Remaining Useful Life (RUL)**

### Target Variable:

* **Failure label**

  * `1` → Engine likely to fail soon (RUL ≤ 30 cycles)
  * `0` → Engine operating normally

## 🧪 Methodology

### 🔹 Data Preprocessing

* Removed non-predictive identifiers
* Normalized sensor readings using Min-Max scaling
* Created a binary failure label from RUL values

### 🔹 Machine Learning Model

* **Algorithm:** Random Forest Classifier
* **Reason:** Robust to noise, interpretable via feature importance
* **Evaluation Metrics:** Precision, Recall, F1-Score

### 🔹 Feature Importance

Important sensor signals were identified using Random Forest feature importance to highlight **critical engine parameters** influencing failure.

### 🔹 Generative AI Integration

A **FLAN-T5 text-to-text model** was used to:

* Convert numerical predictions into explanations
* Describe possible failure causes
* Recommend maintenance actions

This improves **interpretability and trust** in AI predictions.

## 🤖 GenAI Prompt Design

The GenAI component is driven by carefully designed prompts that include:

* Predicted RUL
* Critical sensor indicators
* Explanation instructions

Example prompt:

```
You are an aircraft engine maintenance assistant.
The engine has a predicted Remaining Useful Life of 25 cycles.
Critical sensor readings include: s_11, s_4, s_12, s_7, s_15.
Explain the condition and recommend maintenance actions.
```
